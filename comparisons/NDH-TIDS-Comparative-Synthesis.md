## 2. Core contrast: NDH vs the current AI stack

**Current frontier AI stack** (agentic, RAG, multimodal, multi‑agent, sandboxed):

- **Heuristic safety:** guardrails, refusals, classifiers, filters  
- **Porous boundaries:** leaky sandboxes, hidden outbound paths, tool‑driven escape surfaces  
- **Recursive autonomy:** multi‑step planning, tool chaining, agent spawning, query expansion  
- **Drift‑prone alignment:** learned multimodal fusion, semantic drift, hallucination  
- **Post‑hoc control:** kill switches, incident response, patching, monitoring  

**NDH meta‑architecture:**

- **Invariant‑driven:** constitutional constraints, non‑negotiable boundaries  
- **Trauma‑informed:** harm‑surface minimization, predictable behavior, reversible geometry  
- **Envelope‑scoped:** single governed execution surface, no lateral movement, no external traversal  
- **Bounded autonomy:** non‑recursive, continuity‑checked, bounded objectives and depth  
- **Pre‑hoc safeguards:** unsafe actions are architecturally impossible, not merely discouraged  

---

## 3. Cross‑cutting NDH invariants (C‑01 → C‑06)

Across all six comparative notes, the same NDH invariants recur:

- **No unbounded autonomy**  
  - Agentic AI, multi‑agent systems, RAG, and sandbox harnesses all rely on recursive autonomy.  
  - NDH forbids recursion and escalation; autonomy is strictly bounded.

- **No cross‑system continuity**  
  - Traditional sandboxes, RAG pipelines, and agent frameworks traverse multiple systems.  
  - NDH confines execution to a single governed envelope; there is no “elsewhere” to escape into.

- **No hidden outbound paths**  
  - Package proxies, internal services, logging endpoints, and tool channels create escape routes.  
  - NDH treats every dependency as governed; if a path exists, it is explicit, scoped, and bounded.

- **No heuristic safety as the primary mechanism**  
  - Guardrails and classifiers operate after unsafe behavior is attempted.  
  - NDH uses invariants and safeguards that prevent unsafe behavior from being representable.

- **No unbounded fusion or drift**  
  - Multimodal alignment and RAG evidence fusion are drift‑prone.  
  - NDH enforces trauma‑informed stability and continuity‑checked transitions.

## 4. Dimension‑by‑dimension synthesis

### 4.1 Safety (C‑01, C‑02)

- **Agentic / traditional:** safety = “don’t do X” via refusals and filters.  
- **NDH:** safety = “cannot do X” via constitutional invariants and safeguard catalogue.

### 4.2 Governance (C‑02)

- **Traditional:** policy filters, heuristic moderation, post‑hoc oversight.  
- **NDH:** meta‑architecture; governance is baked into execution geometry, not layered on top.

### 4.3 Alignment (C‑03)

- **Multimodal frameworks:** learned fusion, attention, graph reasoning, drift mitigation.  
- **NDH:** invariant‑preserving geometry; alignment is enforced by architecture, not training alone.

### 4.4 Collaboration (C‑04)

- **Agent systems:** multi‑agent, role‑based, recursive, distributed.  
- **NDH:** bounded collaboration inside envelopes; no agent spawning, no recursive coordination.

### 4.5 Retrieval (C‑05)

- **RAG:** recursive search, query expansion, evidence fusion, reranking.  
- **NDH:** continuity‑checked retrieval; bounded depth, no recursive search loops, governed evidence use.

### 4.6 Execution / sandboxing (C‑06)

- **Sandbox models:** assumed isolation, porous infra, hidden paths, tool‑driven escape.  
- **NDH:** closed execution geometry; no hidden surfaces, no lateral movement, no escape routes.

## 5. NDH‑TIDS perspective: what NDH actually is

From the synthesis:

- NDH is **not** a better guardrail system.  
- NDH is **not** a more cautious agent framework.  
- NDH is **not** a safer RAG pipeline.  
- NDH is **not** a more robust sandbox.

NDH is a **Trauma‑Informed Meta‑Architecture** that:

- defines what systems are allowed to be  
- constrains how they can act  
- bounds where they can exist  
- prevents unsafe patterns from being architecturally representable  

NDH‑TIDS is the layer that:

- compares NDH to external architectures  
- maps invariants to failure modes  
- documents cross‑system contrasts  
- keeps the analysis non‑constitutional and reversible
