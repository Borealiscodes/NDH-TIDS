- retrieval depth

# **3 — RAG System Characteristics**

### **3.1 — Vector Search + Semantic Retrieval**
RAG systems rely on:

- dense embeddings  
- semantic similarity  
- multi‑vector retrieval  
- cross‑encoder reranking  

These are powerful but **drift‑prone**.

### **3.2 — Recursive Search Depth**
RAG pipelines often:

- expand queries  
- refine prompts  
- re‑retrieve  
- re‑rank  
- re‑generate  

This creates:

- recursive loops  
- escalating autonomy  
- unpredictable behavior  

### **3.3 — Evidence Fusion**
RAG systems fuse retrieved evidence via:

- cross‑attention  
- concatenation  
- summarization  
- multi‑modal alignment  

This can produce:

- hallucination  
- misalignment  
- semantic drift  

### **3.4 — Post‑Hoc Safety**
RAG safety relies on:

- classifiers  
- filters  
- moderation layers  

These operate **after** unsafe reasoning has already occurred.

# **4 — NDH Governance Characteristics**

### **4.1 — Continuity‑Checked Retrieval**
NDH enforces:

- continuity constraints  
- invariant‑preserving transitions  
- bounded retrieval envelopes  

A retrieval step cannot:

- escalate  
- recurse  
- expand autonomously  

### **4.2 — Trauma‑Informed Safeguards**
NDH uses:

- harm‑surface minimization  
- predictable behavior  
- reversible geometry  
- safeguard activation  

This prevents:

- drift  
- hallucination  
- unsafe evidence fusion  

### **4.3 — Bounded Reasoning Depth**
NDH defines:

- maximum reasoning depth  
- maximum retrieval depth  
- maximum evidence surface  

These are **constitutional**, not heuristic.

### **4.4 — No Recursive Retrieval**
NDH forbids:

- recursive search loops  
- autonomous query expansion  
- multi‑step retrieval escalation  

This makes RAG‑style runaway loops architecturally impossible.

# **5 — Why NDH Cannot Fail Like RAG Systems**

### **5.1 — No Hallucination Propagation**
RAG hallucination occurs when:

- retrieved evidence is misaligned  
- fusion layers drift  
- semantic grounding weakens  

NDH halts on invariant violation.  
Hallucination cannot propagate.

### **5.2 — No Retrieval Escalation**
RAG systems escalate retrieval depth to:

- improve accuracy  
- refine reasoning  
- expand context  

NDH forbids escalation.

### **5.3 — No Cross‑Boundary Search**
RAG pipelines often:

- call external APIs  
- traverse multiple systems  
- access ungoverned data sources  

NDH prohibits cross‑system continuity.

### **5.4 — No Unbounded Evidence Fusion**
RAG systems fuse:

- multiple documents  
- multiple modalities  
- multiple retrieval passes  

NDH confines evidence to a governed envelope.
