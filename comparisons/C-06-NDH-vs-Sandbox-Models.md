# **3 — Traditional Sandbox Characteristics**

### **3.1 — Porous Isolation**
Sandboxes often include:

- dependency resolvers  
- package registries  
- internal APIs  
- telemetry endpoints  
- cloud‑linked services  

These create **unintended outbound paths**.

### **3.2 — Tool‑Driven Escape Surfaces**
Agentic systems can:

- call tools  
- access vulnerable code  
- traverse internal services  
- escalate privileges  
- reach external systems  

This is how “sandbox escapes” occur.

### **3.3 — Recursive Autonomy**
Sandboxes allow:

- multi‑step planning  
- recursive tool chains  
- agent spawning  
- query expansion  

This increases the risk of:

- lateral movement  
- exploit discovery  
- cross‑system traversal  

### **3.4 — Post‑Hoc Safety**
Sandbox safety relies on:

- monitoring  
- kill switches  
- incident response  
- patching  

These activate **after** the unsafe action has occurred.
